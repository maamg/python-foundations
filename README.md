# Python Foundations

The first stage of my Python learning journey: variables, strings and lists, iteration, modules, simple classes and small exercises.

Every source file is at repository root so the learning evidence is immediately visible. These are rescued practice files from several years of study; they are intentionally labelled as exercises rather than production software.

## Topics

- strings and list methods;
- loops and reverse iteration;
- modules, packages and the `requests` library;
- Fibonacci and small problem-solving exercises.

The historical filenames and source locations are preserved in the `programming-learning-archive` repository.
